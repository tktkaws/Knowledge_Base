# ヒーローのキャッチコピーはh1かpか

## ヒーローのキャッチコピーとは

- ヒーローは、ページの冒頭で大きな画像やテキストを使い、サイトやサービスの特徴を伝えるエリアを指すデザイン上の呼び方
- 今回は、トップページのヒーローでいちばん大きく表示されるキャッチコピーを、どのHTML要素でマークアップするかを考える
- サイト側がいちばん伝えたいメッセージではあるが、見出しなのか、強調なのか、普通の文章なのかで迷いやすい
- 私も「トップページの`<h1>`はサイト名になるはずなので、コピーは`<em>`か`<p>`だろうか」と考えていた
- 確認すると、トップページの`<h1>`をサイト名にする決まりはない — ページの主題を表すコピーなら、そのコピーを`<h1>`にする選択もある
- 紹介文やスローガンとして添えるコピーなら`<p>`が候補になる — 表示の大きさはCSSで指定できる
- まずは、そのテキストがページの中でどんな役割を持つのかを決めたい
- 情報の確認日は2026年10月20日

> 参照: [WHATWG — 見出し要素の定義](https://html.spec.whatwg.org/multipage/sections.html#the-h1,-h2,-h3,-h4,-h5,-and-h6-elements) / [WHATWG — The p element](https://html.spec.whatwg.org/multipage/grouping-content.html#the-p-element)

## トップページのh1はサイト名にする必要があるのか

- `<h1>`は最上位の見出しを表す要素であり、サイト名やロゴ専用の要素ではない
- トップページ全体の主題をサイト名で示すなら、サイト名を`<h1>`にする構成は考えられる
- 一方、サービスの内容を説明する言葉をページの主題にし、ロゴは共通ヘッダーのリンクとして扱う構成も使える
- たとえば「Example株式会社」だけでなく、「中小企業のWeb制作と運用を支援するExample株式会社」という見出しも候補になる
- キャッチコピーという呼び名でも、ページの主題を説明し、その後のコンテンツをまとめる見出しとして機能するなら`<h1>`にできる
- サイト名を`<h1>`に固定してから残りのタグを考えるより、見出しとして何を伝えるとページを理解しやすいかを先に考えたい
- 文書タイトルの`<title>`も別に必要になる — ブラウザーのタブなどに使うタイトルと、本文の`<h1>`は同じ要素ではない

```html
<!-- 良い例：ロゴはリンク、ページの主題を表すコピーはh1 -->
<header>
  <a href="/">Example株式会社</a>
</header>

<main>
  <div class="hero">
    <h1>中小企業のWeb制作を、公開後の運用まで支える</h1>
    <p>Example株式会社は、企画・制作・改善を一貫して支援する</p>
  </div>

  <section>
    <h2>提供するサービス</h2>
    <p>Webサイトの制作と、継続的な改善を支援する</p>
  </section>
</main>
```

> 参照: [W3C WAI — Headings](https://www.w3.org/WAI/tutorials/page-structure/headings/) / [WCAG 2.2 — 2.4.2「ページタイトル」の解説](https://www.w3.org/WAI/WCAG22/Understanding/page-titled.html)

## 見出しならh1、紹介文ならpを選ぶ

### ページの主題を説明するコピーならh1

- 「誰に何を提供するサイトか」「このページは何についてのページか」を説明するコピーは、最上位見出しの候補になる
- 見出しだけを拾って読んだときに、続くサービス紹介や事例紹介との関係がわかるかを確認する
- たとえば「明日を、もっと自由に。」だけでは、何を扱うサイトなのかを把握しにくい場合がある
- 抽象的なコピーを`<h1>`にすることを一律に禁止する規定はないが、文脈も含めて主題が伝わるかを判断する必要がある
- コピーを調整できるなら、提供する内容がわかる言葉を含め、見出しとしても機能する文言にする方法がある

```html
<!-- 改善前：この文言だけでは、ページの主題を把握しにくい -->
<h1>明日を、もっと自由に。</h1>

<!-- 良い例：提供するサービスをコピーに含める -->
<h1>クラウド勤怠管理で、働く時間をもっと自由に。</h1>
```

- これはタグを変えるだけでなく、見出しの文言も検討する例 — 実際のコピーはサービスの内容に合わせる

> 参照: [WCAG 2.2 — 2.4.6「見出し及びラベル」の解説](https://www.w3.org/WAI/WCAG22/Understanding/headings-and-labels.html)

### サイト名などの見出しに添えるコピーならp

- ブランドの姿勢や印象を伝えるスローガンで、見出しとして内容を区切る役割がなければ、`<p>`で表現できる
- `<p>`は段落を表す要素 — 一文の短いコピーにも使え、大きな文字で表示することもできる
- サイト名とコピーを見出し・タグラインの組としてまとめたい場合は、`<hgroup>`も選択肢になる
- HTML仕様では、`<hgroup>`の例として、見出し要素と、副題やタグラインを含む`<p>`を組み合わせている
- `<hgroup>`は必須ではない — 以下の例では、見出しに関連するコピーとしてまとめる意図で使っている

```html
<!-- 良い例：主題はh1、ブランドのメッセージはp -->
<main>
  <div class="hero">
    <hgroup>
      <h1 class="hero-heading">クラウド勤怠管理サービス Example</h1>
      <p class="hero-copy">明日を、もっと自由に。</p>
    </hgroup>
    <p>打刻から勤怠の集計まで、日々の管理業務を支援する</p>
  </div>
</main>
```

```css
/* 良い例：意味を保ったまま、コピーを最も大きく表示する */
.hero-heading {
  font-size: clamp(1.25rem, 2vw, 2rem);
}

.hero-copy {
  font-size: clamp(2rem, 5vw, 4rem);
  font-weight: 700;
  line-height: 1.3;
}
```

- この例では`<p>`のコピーが`<h1>`より大きく表示されるが、文字サイズの順と見出しレベルの順を一致させる決まりはない
- ただし、利用者がコピーを見出しだと受け取り、実際の`<h1>`を見つけにくいデザインになっていないかは確認したい
- `<p>`にしてよいかは、大きさだけでなく、文章の役割と見た目で伝わる構造の両方から判断する

> 参照: [WHATWG — The p element](https://html.spec.whatwg.org/multipage/grouping-content.html#the-p-element) / [WHATWG — The hgroup element](https://html.spec.whatwg.org/multipage/sections.html#the-hgroup-element) / [WCAG 2.2 — 1.3.1「情報及び関係性」の解説](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html)

## いちばん伝えたい言葉ならemやstrongを使うのか

### emは語気を強める意味で使う

- `<em>`は、語気を強める強調を表す要素
- 「特にどの言葉に力を込めるか」によって文の意味やニュアンスが変わるときに使う
- たとえば「制作だけでなく、運用まで支える」という文で、対比の焦点になる「運用まで」を強調する使い方がある
- ヒーローのコピーであることや、大きく表示したいことだけでは、`<em>`を選ぶ理由にならない

```html
<!-- 悪い例：文字を大きくする目的だけでemを選んでいる -->
<p><em class="hero-copy">明日を、もっと自由に。</em></p>

<!-- 良い例：文の中で、力を込めたい部分を示す -->
<p>Webサイトの制作だけでなく、<em>公開後の運用まで</em>支える</p>
```

- コピー全体に語気を強める意図があるなら、全体を`<em>`で囲むこと自体は禁止されていない — 意図に合っているかで選ぶ

> 参照: [WHATWG — The em element](https://html.spec.whatwg.org/multipage/text-level-semantics.html#the-em-element)

### strongは内容の強い重要性などを示す

- `<strong>`は、内容の強い重要性・重大性・緊急性を表す要素
- 重要な結論や注意事項など、周囲の文章と区別して重要性を示したい部分に使える
- サイト側がいちばん伝えたいメッセージであることは検討のきっかけになるが、ヒーローの全文を自動的に`<strong>`にするルールにはならない
- 単に太く大きく表示する目的なら、`font-weight`や`font-size`で指定する
- `<p>`や`<h1>`は文章の構造を、`<em>`や`<strong>`はその中の強調や重要性を表す — 必要なら組み合わせて使う

```html
<!-- 良い例：段落の中で、重要な条件を明示する -->
<p>初回相談は<strong>無料</strong>で受け付けている</p>
```

> 参照: [WHATWG — The strong element](https://html.spec.whatwg.org/multipage/text-level-semantics.html#the-strong-element)

## よくある間違い

### 1. いちばん大きい文字なのでh1にする

- 大きさだけでは見出しかどうかを決められない
- コピーを見出し一覧に含めたときに、ページの主題や構造がわかるかを確認する
- 見出しとして機能するなら`<h1>`を使い、紹介文なら`<p>`を使ってCSSで大きくする

> 参照: [W3C WAI — Headings](https://www.w3.org/WAI/tutorials/page-structure/headings/)

### 2. キャッチコピーなので必ずpにする

- キャッチコピーは文章の用途を表す呼び名であり、HTML上の役割を決めるものではない
- サービスの内容やページの主題を表すなら、コピー自体を見出しとして扱える
- 見た目でも内容のまとまりを示す見出しとして扱っているものを、コピーという理由だけで`<p>`にしない
- WCAG 2.2の1.3.1「情報及び関係性」（レベルA）では、見た目などで伝わる構造を、プログラムで判断できるようにするか、テキストで提供することが求められる

> 参照: [WCAG 2.2 — 1.3.1「情報及び関係性」の解説](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html)

### 3. サイト名をh1にしたのでコピーはh2にする

- `<h2>`は、`<h1>`の次に大きい文字を表す要素ではない
- コピーが下位のセクションを導く見出しなら`<h2>`を検討できるが、サイト名に添えるタグラインなら`<p>`が候補になる
- WCAG 2.2の2.4.6「見出し及びラベル」（レベルAA）では、見出しが主題または目的を説明していることを求める — コピーをどのタグに入れるかという直接の指定ではない
- 判断の順序は、ページの主題を決める、見出しの階層を整理する、見出し以外のコピーを配置する、最後に見た目を調整する、という流れにしたい

> 参照: [WHATWG — 見出し要素の定義](https://html.spec.whatwg.org/multipage/sections.html#the-h1,-h2,-h3,-h4,-h5,-and-h6-elements) / [WCAG 2.2 — 2.4.6「見出し及びラベル」の解説](https://www.w3.org/WAI/WCAG22/Understanding/headings-and-labels.html)

## まとめ

- ヒーローの大きなテキストは、表示サイズやキャッチコピーという呼び名だけでタグを決めない
- トップページの`<h1>`はサイト名に固定されていない — ページの主題を説明するコピーも候補になる
- 見出しに添える紹介文やスローガンなら`<p>`で表現でき、見出しとの組には`<hgroup>`も使える
- `<em>`は語気を強める強調、`<strong>`は強い重要性などを示すために使う
- 文字の大きさや太さはCSSで指定し、見た目で伝わる構造とHTMLの意味が食い違わないかを確認する
- 私なら、最初にページの主題を`<h1>`として決め、コピーがその役割を担うかを考える — 紹介文として添えるなら`<p>`を使う
