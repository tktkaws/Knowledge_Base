# Tabs — タブ

## 用途

関連する複数のパネルを重ね、一度に一つを表示する。別ページへ移動するナビゲーションや、順に入力するウィザードとは区別する。

## 構造とARIA

- 名前付きの `tablist` の中に `tab` を置き、対応する `tabpanel` と `aria-controls` / `aria-labelledby` で関連付ける。
- 選択されたタブだけ `aria-selected="true"` とし、表示パネルも同期する。

## キーボードとフォーカス

- 横型では左右矢印でタブ間を移動する。縦型では上下矢印を使う。`Home` / `End` は任意。
- 手動切り替えでは `Enter` / `Space` で表示する。自動切り替えは、フォーカス移動時に遅延なく表示できる場合に適している。
- `Tab` でタブ群へ出入りし、タブを一つずつTab順序に並べない。

## 実装時に確認すること

フォーカス位置と選択状態を区別する。横型で上下矢印を奪ってページスクロールを妨げない。
