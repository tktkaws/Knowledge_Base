# Dialog (Modal) — モーダルダイアログ

[APG記事一覧](./README.md) / [共通の実装原則](./practices.md)

> 出典: [W3C APG — Dialog (Modal)](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)（確認日: 2026-11-16）
> 公式パターンの要約と既存記事の案内。操作の選択肢や詳細な条件は原文を参照する。

## 用途

背後の操作を一時的に止め、ダイアログ内の作業に集中させる。端から出るパネルでも、背後を操作できないならこのパターンが候補になる。

## 構造とARIA

- ダイアログに名前を付ける。ARIAによる実装では `dialog` と `aria-modal="true"` を使い、背後を実際に操作不能にする。
- `aria-describedby` は任意。表や複数段落を含む長い本文を、一続きの説明として関連付けない。

## キーボードとフォーカス

- 開くと内部へフォーカスを移す。長い本文なら冒頭の見出しなど、内容を理解しやすい位置を選ぶ。
- `Tab` / `Shift + Tab` は内部で循環し、`Escape` で閉じる。閉じたら呼び出し元、または次の作業として自然な位置へ戻す。

## 実装時に確認すること

属性の指定とモーダルの実際の動作を一致させる。閉じるボタンを用意し、ネイティブのdialogを使う場合も初期フォーカスと復帰先を確認する。
