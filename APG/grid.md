# Grid (Interactive Tabular Data and Layout Containers) — グリッド

## 用途

矢印キーでセルや操作部品を移動する複合ウィジェット。表形式のデータグリッドと、リンクや部品をまとめるレイアウトグリッドがある。CSS Gridとは別の概念。

## 構造とARIA

- `grid`、`row`、`gridcell` または見出しセルのロールで構造を示し、グリッドに名前を付ける。
- セル自体、またはセル内の要素へフォーカスできるようにする。操作のない見出しセルは例外。
- 選択、編集、並べ替えがある場合は、その状態も伝える。

## キーボードとフォーカス

- 通常、ページのTab順序にはグリッド内の一つだけを含め、内部は矢印キーで移動する。
- データ型とレイアウト型では端での移動などが異なる。セル内に入力欄がある場合は、セル移動と文字編集の操作を分ける。

## 実装時に確認すること

ソートボタンやリンクを含むだけでTableをGridへ変えない。読み上げと通常のTab操作で十分か、二次元の移動が必要かで判断する。汎用データグリッドの専用記事は未作成。
