# ブロックエディタの基本と操作方法

## 概要

- WordPress 5.0（2018年12月）で導入されたエディタ
- 開発コードネームは「Gutenberg（グーテンベルク）」
- コンテンツを「ブロック」という単位で組み立てる
- 旧エディタ（Classic Editor）のような1つの大きなテキストエリアではなく、段落・見出し・画像などがそれぞれ独立したブロックになる

### 参照元

- [WordPress Block Editor Handbook](https://developer.wordpress.org/block-editor/)

---

## クラシックエディタとの違い

| 項目 | クラシックエディタ | ブロックエディタ |
|------|-------------------|-----------------|
| 編集単位 | 1つのリッチテキストエリア | ブロック単位 |
| レイアウト | HTMLを直接書く必要あり | カラムブロックなどで視覚的に構成 |
| 再利用 | コピペで対応 | 再利用ブロック・パターンで管理 |
| カスタマイズ | ショートコード中心 | ブロック単位で拡張可能 |
| プレビュー | 別画面で確認 | 編集画面がほぼそのまま表示に近い |

### 参照元

- [Classic Editor – WordPress plugin](https://wordpress.org/plugins/classic-editor/)

## エディタ画面の構成

### メインエリア

- 画面中央のコンテンツ編集領域
- ブロックを追加・編集・並び替えする場所
- 実際の表示に近い見た目で編集できる（WYSIWYGに近い）

### トップツールバー

- 左側
  - ブロック挿入ツール（`+` ボタン）
  - 元に戻す / やり直し
  - リスト表示（ドキュメント概観）
- 右側
  - 下書き保存
  - プレビュー
  - 公開 / 更新

### 設定サイドバー（右側）

- 「投稿」タブ：投稿全体の設定（カテゴリ、タグ、アイキャッチ画像、抜粋など）
- 「ブロック」タブ：選択中のブロック固有の設定（色、フォントサイズ、余白など）

### 参照元

- [WordPress Block Editor Handbook – Getting Started](https://developer.wordpress.org/block-editor/getting-started/)

## ブロックの基本操作

### ブロックの追加

- 方法1：空のブロックで `/` を入力してブロック名を検索（スラッシュコマンド）
- 方法2：ツールバー左の `+` ボタンからブロック一覧を開く
- 方法3：ブロック間に表示される `+` ボタンをクリック
- 方法4：`Enter` キーで新しい段落ブロックが追加される

```
# スラッシュコマンドの例
/heading    → 見出しブロック
/image      → 画像ブロック
/columns    → カラムブロック
/list       → リストブロック
/quote      → 引用ブロック
```

### ブロックの選択

- ブロックをクリックして選択
- `Escape` キーで選択モード（ブロック全体を選択した状態）に切り替え
- 選択モードで `Enter` を押すと編集モードに戻る

### ブロックの移動

- ブロック左のツールバーにあるドラッグハンドル（6点アイコン）でドラッグ＆ドロップ
- 上下矢印ボタンで1つずつ移動
- ブロックツールバーの「…」メニューから「前に移動」「後に移動」

### ブロックの削除

- ブロックツールバーの「…」メニュー →「ブロックを削除」
- ブロック選択状態で `Shift + Alt + Z`（Windows）/ `Ctrl + Option + Z`（Mac）

### ブロックの複製

- ブロックツールバーの「…」メニュー →「複製」
- `Ctrl + Shift + D`（Windows）/ `Cmd + Shift + D`（Mac）

### 参照元

- [WordPress Block Editor Handbook – Working with blocks](https://developer.wordpress.org/block-editor/getting-started/tutorial/)

## よく使うコアブロック

### テキスト系

| ブロック名 | 用途 |
|-----------|------|
| 段落 | 本文テキスト。最も基本的なブロック |
| 見出し | H2〜H6の見出し |
| リスト | 箇条書き・番号付きリスト |
| 引用 | 引用文の表示 |
| コード | コードスニペットの表示 |
| テーブル | 表の作成 |

### メディア系

| ブロック名 | 用途 |
|-----------|------|
| 画像 | 単体の画像挿入 |
| ギャラリー | 複数画像の一覧表示 |
| 動画 | 動画ファイルの埋め込み |
| メディアとテキスト | 画像とテキストを横並びに配置 |

### レイアウト系

| ブロック名 | 用途 |
|-----------|------|
| カラム | 2カラム・3カラムなどの段組み |
| グループ | 複数ブロックをまとめる |
| スペーサー | ブロック間の余白を調整 |
| 区切り | 水平線で区切りを入れる |

### 参照元

- [WordPress Core Blocks Reference](https://developer.wordpress.org/block-editor/reference-guides/core-blocks/)

## ブロックツールバー

- 各ブロックの上部に表示される操作バー
- ブロックの種類に応じた操作が並ぶ

### 段落ブロックの場合

```
[¶ 段落 ▼] [B] [I] [🔗] [▼] ... [⋮]
   ↑        ↑   ↑   ↑    ↑       ↑
   ブロック  太字 斜体 リンク 追加   その他
   タイプ変更                書式
```

### ブロックタイプの変換

- ツールバー左端のアイコンをクリック
- 互換性のあるブロックに変換できる
- 例：段落 → 見出し、リスト → 段落、引用 → 段落

### 参照元

- [WordPress Block Editor Handbook – Block Toolbar](https://developer.wordpress.org/block-editor/how-to-guides/block-tutorial/block-controls-toolbar-and-sidebar/)

## リスト表示（ドキュメント概観）

- トップツールバーの三本線アイコン、または `Shift + Option + O`（Mac）で開く
- ページ内の全ブロックをツリー構造で表示
- ブロックの入れ子関係が視覚的にわかる
- リスト表示からブロックをドラッグして並び替え可能
- ブロック数が多いページの編集で特に便利

### 参照元

- [WordPress Block Editor Handbook – List View](https://developer.wordpress.org/block-editor/how-to-guides/accessibility/)

## ブロックの設定サイドバー

- ブロックを選択すると右サイドバーに「ブロック」タブが表示される
- ブロックの種類に応じた設定項目が並ぶ

### 段落ブロックの設定例

- **タイポグラフィ**：フォントサイズ、行の高さ、文字間隔
- **色**：テキスト色、背景色
- **寸法**：パディング、マージン
- **高度な設定**：HTMLアンカー、追加CSSクラス

### 追加CSSクラスの活用

- 「高度な設定」→「追加CSSクラス」にクラス名を入力
- テーマのCSSやカスタマイザーの追加CSSでスタイルを当てられる

```css
/* 良い例：追加CSSクラスを使ってスタイルを適用 */
.highlight-box {
  background-color: #fff3cd;
  border-left: 4px solid #ffc107;
  padding: 1rem;
}
```

```html
<!-- ブロックに .highlight-box を追加CSSクラスとして指定 -->
<p class="highlight-box">重要なお知らせです。</p>
```

## 再利用ブロック（同期パターン）

- 複数の投稿で同じブロックを使い回す仕組み
- WordPress 6.3以降は「同期パターン」という名称に変更
- 同期パターンを編集すると、使われているすべての場所に反映される

### 作成手順

1. 再利用したいブロックを選択
2. ブロックツールバーの「…」→「パターンを作成」
3. 名前をつけて「同期」を有効にして保存

### 使いどころ

- CTAバナー
- お問い合わせ情報
- 免責事項・注意書き
- 共通のヘッダー・フッターコンテンツ

### 注意点

- 同期パターンを編集すると全箇所に影響する
- 個別に変更したい場合は「パターンを解除」して通常ブロックに変換する

### 参照元

- [WordPress Patterns](https://developer.wordpress.org/block-editor/reference-guides/block-api/block-patterns/)

## エディタの表示モード

### トップツールバーモード

- デフォルトではブロックツールバーがブロック直上に表示される
- 「設定」→「トップツールバー」を有効にすると、すべてのツールバーが画面上部に固定される
- ブロック上のツールバーが邪魔な場合に便利

### スポットライトモード

- 「設定」→「スポットライトモード」を有効化
- 選択中のブロック以外が薄く表示される
- 長い記事の編集で集中しやすい

### フルスクリーンモード

- 「設定」→「フルスクリーンモード」を有効化（デフォルトで有効）
- WordPress管理画面のサイドバーが非表示になり、編集領域が広がる

### コードエディタ

- 「…」メニュー →「コードエディタ」、または `Ctrl + Shift + Alt + M`（Win）/ `Cmd + Shift + Option + M`（Mac）
- ブロックのHTMLマークアップを直接編集できる
- ブロックの構造を確認したいときに便利
- 慣れないうちはブロックが壊れる原因になるので注意

### 参照元

- [WordPress Editor Settings](https://wordpress.org/documentation/article/blocks-list/)

## トラブルシューティング

### 「このブロックには、想定されていないか無効なコンテンツが含まれています」

- ブロックのHTMLが期待される構造と異なるときに表示される
- 原因：コードエディタでの手動編集ミス、プラグインのアップデートなど
- 対処法：「ブロックのリカバリーを試行」をクリック、または「HTMLに変換」して手動で修正

### ブロックが選択できない

- リスト表示を使って目的のブロックを選択する
- ブラウザのキャッシュをクリアする
- プラグインの競合を確認する（プラグインを一時的に無効化して検証）

### エディタが重い・遅い

- ブロック数が多すぎる場合はページを分割する
- 不要なプラグインを無効化する
- ブラウザの開発者ツールでエラーを確認する

### 参照元

- [WordPress Troubleshooting](https://wordpress.org/documentation/article/faq-troubleshooting/)
