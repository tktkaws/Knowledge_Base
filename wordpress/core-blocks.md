# コアブロックの種類と使い分け

## 概要

- WordPressが標準で提供するブロック群
- プラグインなしで使えるため、互換性・保守性が高い
- WordPress 6.x系で約90種類以上が用意されている
- カテゴリ別に整理されており、用途に応じて選択する

### 参照元

- [WordPress Core Blocks Reference](https://developer.wordpress.org/block-editor/reference-guides/core-blocks/)

---

## テキストブロック

### 段落（Paragraph）

- 最も基本的なブロック。本文テキストに使う
- `Enter` キーで自動的に新しい段落ブロックが作られる
- ドロップキャップ（先頭文字の装飾）に対応

```html
<!-- 良い例：段落ブロックで本文を記述 -->
<p>WordPressのブロックエディタでは、段落ごとにブロックが分かれます。</p>

<!-- 悪い例：1つの段落ブロック内で <br> を多用して改行する -->
<p>1行目のテキスト<br><br>2行目のテキスト<br><br>3行目のテキスト</p>
```

### 見出し（Heading）

- H1〜H6を指定できる（通常H2〜H4を使う）
- H1はページタイトルに使われるため、本文中では使わない
- 見出しレベルは順序を守る（H2の下にH4を置かない）

```html
<!-- 良い例：見出しレベルを正しい順序で使う -->
<h2>セクションタイトル</h2>
<h3>サブセクション</h3>

<!-- 悪い例：見出しレベルを飛ばす -->
<h2>セクションタイトル</h2>
<h4>サブセクション</h4>
```

### リスト（List）

- 順序なしリスト（箇条書き）と順序ありリスト（番号付き）を切り替え可能
- インデントで入れ子のリストを作れる
- WordPress 6.1以降、リスト内の各項目が独立したブロック（リスト項目ブロック）になっている

### 引用（Quote）

- 他のサイトや文献からの引用文を示す
- 引用元（citation）を記入するフィールドがある
- `<blockquote>` タグで出力される

### コード（Code）

- コードスニペットをそのまま表示する
- 入力内容がHTMLエスケープされるため、タグがそのまま表示される
- シンタックスハイライトはデフォルトでは付かない（プラグインで対応）

### プルクオート（Pullquote）

- 記事内の重要なフレーズを強調表示するブロック
- 引用ブロックとは用途が異なる（外部引用ではなく記事内の強調）
- 装飾的なスタイルが適用される

### テーブル（Table）

- シンプルな表を作成できる
- ヘッダー行・フッター行の有無を設定可能
- セルの結合はできない（複雑な表はカスタムHTMLブロックで対応）
- 「ストライプ」スタイルで交互に背景色をつけられる

### 詳細（Details）

- WordPress 6.3で追加
- `<details>` / `<summary>` タグで出力されるアコーディオンUI
- FAQ、補足情報、長い説明文の折りたたみに便利

### 脚注（Footnotes）

- WordPress 6.3で追加
- 記事内に脚注を挿入し、ページ下部に脚注リストを自動生成
- テキストを選択して「脚注」書式を適用すると自動で番号が振られる

### 参照元

- [WordPress Core Blocks Reference – Text](https://developer.wordpress.org/block-editor/reference-guides/core-blocks/)

## メディアブロック

### 画像（Image）

- 単体の画像を挿入するブロック
- アップロード、メディアライブラリ、URLから挿入の3通り
- alt属性（代替テキスト）を必ず設定する
- デュオトーン（2色フィルター）やボーダーの設定が可能

### ギャラリー（Gallery）

- 複数画像をグリッド表示するブロック
- カラム数を指定可能
- 各画像にキャプションを設定できる
- 画像の順番はドラッグで並び替え可能

### 音声（Audio）

- 音声ファイル（MP3など）を埋め込むブロック
- ブラウザ標準の `<audio>` プレーヤーで再生される
- 自動再生・ループの設定が可能

### カバー（Cover）

- 背景画像や背景色の上にテキストを重ねるブロック
- ヒーローセクションやバナーの作成に使う
- オーバーレイの色と不透明度を調整できる
- 背景の固定表示（パララックス効果）に対応

```
<!-- カバーブロックの使い分け -->

カバーブロック → 画像の上にテキストを重ねたい場合
画像ブロック   → 画像をそのまま表示したい場合
メディアとテキスト → 画像とテキストを横並びにしたい場合
```

### メディアとテキスト（Media & Text）

- 画像（または動画）とテキストを横並びに配置するブロック
- モバイルで自動的に縦並びにスタックできる
- 画像の左右配置を切り替え可能

### ファイル（File）

- ダウンロード可能なファイルを配置するブロック
- PDF、ZIPなど任意のファイルをアップロードできる
- ダウンロードボタンの表示・非表示を切り替え可能

### 参照元

- [WordPress Core Blocks Reference – Media](https://developer.wordpress.org/block-editor/reference-guides/core-blocks/)

## デザインブロック

### カラム（Columns）

- コンテンツを段組み（2〜6カラム）で配置するブロック
- 各カラムの幅を個別に設定できる
- プリセット（50/50、33/66など）から選択可能

```html
<!-- 良い例：カラムブロックでレイアウトを組む -->
<!-- wp:columns -->
<div class="wp-block-columns">
  <!-- wp:column {"width":"66.66%"} -->
  <div class="wp-block-column" style="flex-basis:66.66%">
    <p>メインコンテンツ</p>
  </div>
  <!-- /wp:column -->
  <!-- wp:column {"width":"33.33%"} -->
  <div class="wp-block-column" style="flex-basis:33.33%">
    <p>サイドバー的な内容</p>
  </div>
  <!-- /wp:column -->
</div>
<!-- /wp:columns -->

<!-- 悪い例：tableタグでレイアウトを組む -->
<table>
  <tr>
    <td>メインコンテンツ</td>
    <td>サイドバー</td>
  </tr>
</table>
```

### グループ（Group）

- 複数ブロックをひとまとめにするブロック
- まとめたブロックに共通の背景色・余白・ボーダーを設定できる
- レイアウトオプション：通常フロー、横並び（Row）、スタック（Stack）、グリッド（Grid）
- セクション単位でスタイルをまとめたいときに使う

### 行（Row）

- ブロックを横並びに配置するブロック
- グループブロックの「Row」レイアウトと同じ挙動
- ボタンやアイコンを横に並べるときに便利

### スタック（Stack）

- ブロックを縦並びに配置するブロック
- グループブロックの「Stack」レイアウトと同じ挙動
- 要素間の間隔（gap）を統一的に制御できる

### スペーサー（Spacer）

- ブロック間に余白を挿入するブロック
- ピクセル単位で高さを指定する
- 多用するとメンテナンスが難しくなるため、theme.jsonのspacing設定を優先すべき

### 区切り（Separator）

- 水平線でコンテンツを区切るブロック
- スタイル：デフォルト（短い線）、幅広（全幅の線）、ドット
- セクション間の視覚的な区切りに使う

### ボタン（Buttons / Button）

- CTAボタンを配置するブロック
- 複数のボタンを横並びに配置可能（Buttonsブロック内にButtonブロックを配置）
- リンク先URL、スタイル（塗りつぶし/アウトライン）を設定
- 幅（25% / 50% / 75% / 100%）を指定可能

### 参照元

- [WordPress Core Blocks Reference – Design](https://developer.wordpress.org/block-editor/reference-guides/core-blocks/)

## ウィジェットブロック

### 最新の投稿（Latest Posts）

- 最新の投稿一覧を表示するブロック
- 表示件数、カテゴリのフィルタ、抜粋の表示、アイキャッチ画像の表示を設定可能
- リスト表示とグリッド表示を切り替えられる

### カテゴリー一覧（Categories）

- 投稿カテゴリの一覧を表示するブロック
- ドロップダウン表示、投稿数の表示、階層の表示を設定可能

### アーカイブ（Archives）

- 月別アーカイブのリンク一覧を表示するブロック
- ドロップダウン形式にも切り替え可能

### カスタムHTML（Custom HTML）

- HTMLを直接記述できるブロック
- 埋め込みコード（iframe、外部ウィジェットなど）の貼り付けに使う
- 使いすぎるとブロックエディタの利点が薄れるため、必要最小限にとどめる

```html
<!-- 良い例：外部サービスの埋め込みコードをカスタムHTMLで配置 -->
<iframe src="https://example.com/embed" width="600" height="400"></iframe>

<!-- 悪い例：通常の段落や見出しをカスタムHTMLで書く -->
<h2>見出し</h2>
<p>段落テキスト</p>
```

### ショートコード（Shortcode）

- 従来のショートコードを使うためのブロック
- 既存プラグインのショートコードを使い続ける場合に使用
- 新規開発ではブロックで代替することが推奨される

### 参照元

- [WordPress Core Blocks Reference – Widgets](https://developer.wordpress.org/block-editor/reference-guides/core-blocks/)

## 埋め込みブロック

### 埋め込み（Embed）

- URLを貼り付けるだけで外部コンテンツを埋め込める
- oEmbed規格に対応したサービスは自動でプレビュー表示される

### 対応サービス例

| サービス | 用途 |
|---------|------|
| YouTube | 動画の埋め込み |
| Twitter（X） | ツイートの埋め込み |
| Instagram | 投稿の埋め込み |
| Spotify | 音楽・ポッドキャストの埋め込み |
| WordPress | 他のWordPressサイトの投稿埋め込み |
| TikTok | 動画の埋め込み |

### 使い方

- 段落ブロックにURLを貼り付けると自動で埋め込みブロックに変換される
- または「埋め込み」ブロックを選択してURLを入力する
- 埋め込みがうまくいかない場合は、oEmbedに対応していない可能性がある

### 参照元

- [WordPress Embeds](https://developer.wordpress.org/block-editor/reference-guides/core-blocks/#embed)

## テーマブロック（FSE用）

- Full Site Editing（FSE）対応テーマで使用するブロック
- サイト全体のテンプレート（ヘッダー・フッターなど）を編集するためのブロック群
- クラシックテーマでは通常使わない

### 主なテーマブロック

| ブロック名 | 用途 |
|-----------|------|
| サイトタイトル | サイト名を動的に表示 |
| サイトロゴ | サイトのロゴ画像を表示 |
| ナビゲーション | ナビゲーションメニューを表示 |
| クエリループ | 投稿一覧を動的に表示（ループ処理） |
| 投稿タイトル | 個別投稿のタイトルを動的に表示 |
| 投稿コンテンツ | 個別投稿の本文を動的に表示 |
| 投稿日 | 投稿日を動的に表示 |
| 投稿カテゴリー | カテゴリーを動的に表示 |
| アイキャッチ画像 | アイキャッチ画像を動的に表示 |
| テンプレートパーツ | ヘッダー・フッターなどの共通パーツを参照 |

### クエリループブロックの使い方

- 投稿タイプ、カテゴリ、タグなどでフィルタリング可能
- 表示件数、並び順を設定できる
- 内部のブロック構成でレイアウトを自由にカスタマイズ
- `WP_Query` 相当の機能をノーコードで実現する

### 参照元

- [WordPress Core Blocks Reference – Theme](https://developer.wordpress.org/block-editor/reference-guides/core-blocks/)
- [WordPress Full Site Editing](https://developer.wordpress.org/block-editor/getting-started/full-site-editing/)

## ブロック選びの判断基準

### テキスト表示

```
本文を書く           → 段落
セクションを分ける   → 見出し
箇条書きにする       → リスト
他からの引用を示す   → 引用
記事内の重要文を強調 → プルクオート
コードを表示する     → コード
表を作る             → テーブル
折りたたみたい       → 詳細
```

### 画像・メディアの配置

```
画像を1枚表示           → 画像
画像を複数並べる         → ギャラリー
画像の上にテキストを重ねる → カバー
画像とテキストを横並び     → メディアとテキスト
ダウンロードファイルを提供 → ファイル
外部動画を埋め込む       → 埋め込み（YouTube等）
```

### レイアウト

```
横に並べる               → カラム
ブロックをまとめる       → グループ
ボタンを並べる           → ボタン
余白を入れる             → スペーサー（※ theme.json推奨）
区切り線を入れる         → 区切り
```
