# WordPressとmicroCMS — セキュリティを揃えたときの最安プラン

## この記事で並べるもの

- 前の記事は、プランごとの機能と段差 — この記事は「対策を入れたときの最安」を月額で1本にする
- 前提はコーポレート1本 — 会員、予約、EC は含まない
- WordPress は4つを足す — ACF PRO の最安、WordPress が動くレンタルサーバーの最安、保守の一般的な月額、ドメインの更新
- microCMS は4つを足す — 有料プランの最安（Team）、静的配信の一般的な最安、保守（基本不要なので 0 円）、ドメインの更新
- ドメインは両側とも同じ1つ — `.com` の更新 **年額 1,721 円**（税込、XServerドメイン。月あたり **143 円**）。初年度の 0 円キャンペーンは維持費に入れない
- ロリポップ ライトに、サーバー契約中のドメイン更新無料は付かない — エックスサーバーのように更新が 0 円になる特典は、この行では使わない
- 金額は 2026年10月時点の公開情報 — 税の扱いが項目で違うので、表の合計は桁の比較として読む
- 制作費と初期構築は含まない

> 参照: [WordPressとmicroCMS — セキュリティ対策とランニングコストで比べる](./wordpress-vs-microcms-security.md)

## WordPress側の最安

- ライセンスが 0 円でも、フィールドの有料プラグインと、更新を人に頼む月額は残る
- ACF（Advanced Custom Fields）PRO はセキュリティ製品ではない — 繰り返しフィールドなどを使う案件のライセンスとして、最安の Personal を足す
- Personal は **1 サイト**、年額 **49 米ドル**（税別。税金は購入時に加算される）
- 円への換算は購入日のレート — この記事の月額は **1 ドル = 150 円** と置いた **年 7,350 円 / 月あたり約 613 円**。レートが変わるとこの行だけ動く
- 更新を受け続けるには年ごとの更新が要る — 切れると PRO の機能追加は止まり、表示側はそのまま残る契約になっている

- サーバーの最安は、WordPress がインストールできるプランの最安 — ロリポップのエコノミー（36ヶ月で月額 121 円）は WordPress 非対応なので、ここには置かない
- 該当するのはロリポップのライト — 36ヶ月契約で月額 **330 円**。1ヶ月契約だと月額 **605 円**。初期費用は 0 円
- ライトには WAF、海外アタックガード、Web 改ざん通知、無料 SSL が付く
- 自動バックアップはライトの標準には無い — ハイスピード以上（36ヶ月で月額 **660 円**）で無料になる。7世代バックアップは有料オプション
- この記事の本線はライトの **330 円** — 切り戻し用のバックアップは、次の保守の作業に含める

- 保守の一般的な価格は、中小のコーポレートで月額 **1 万〜3 万円** と複数の制作会社が書いている — 公的な統計ではない
- 「ちゃんと」の下端として、この記事は月額 **10,000 円** を置く
- 10,000 円に含める作業は3つ — 本体・プラグイン・テーマの更新、バックアップ、セキュリティの確認（不正ログインや改ざんの通知を見る）
- 月額 5,000 円前後のプランは、自動更新とバックアップだけで監視が入らないことが多い — 対策を揃える行には置かない
- 障害からの復旧、改ざんの除去、記事の更新代行は、10,000 円の外に出る契約がある — 見積もりの明細で、上の3つが入っているかを見る
- SiteGuard のようなログイン強化のプラグイン自体は無料 — 費用は導入と、その後の確認の作業

| 項目 | 置き方 | 月額 |
|---|---|---|
| ACF PRO Personal | 年額 49 米ドル。1 ドル = 150 円で月割り | **約 613 円** |
| レンタルサーバー | ロリポップ ライト、36ヶ月契約。WAF 付き。WordPress 対応の最安 | **330 円** |
| ドメイン | `.com` の更新。年額 1,721 円（税込） | **143 円** |
| 保守 | 更新、バックアップ、セキュリティ確認。相場 1〜3 万円の下端 | **10,000 円** |
| 合計 | | **約 11,086 円** |

- 年額に戻すと **133,031 円** — 内訳は ACF 7,350 円 + サーバー 3,960 円 + ドメイン 1,721 円 + 保守 120,000 円
- 合計の約 9 割は保守 — サーバー、ACF、ドメインを足しても、月額の桁は 1 万円のまま

> 参照: [ACF PRO](https://www.advancedcustomfields.com/pro/) / [ロリポップ 料金](https://lolipop.jp/pricing/) / [ロリポップ WAF](https://lolipop.jp/service/specs/waf/) / [XServerドメイン .com](https://www.xdomain.ne.jp/domain/detail/com.php) / [WordPress保守の費用相場（月額1〜3万円）](https://gelatocms.com/blog/wordpress-maintenance/)

## microCMS側の最安

- 有料の最安は Team — 月額 **4,900 円**（税抜）。Hobby の 0 円はこの行に置かない
- 配信の一般的な最安は、静的ホスティングの無料枠 — Cloudflare Pages は帯域無制限、ビルドは月 **500** 回、月額 **0 円**
- PHP 用のレンタルサーバーは、この構成では要らない — 公開面はビルド済みのファイル
- 保守の月額は **0 円** — コア、プラグイン、PHP の更新契約が無い。入稿基盤の更新はベンダー側
- 残る作業は、フロントの依存パッケージの更新と、API キーの棚卸し — 毎月の保守契約にはしない
- ドメインは WordPress 側と同じ — `.com` の更新 **年額 1,721 円**（税込、月あたり **143 円**）
- コンテンツの履歴は Git と microCMS 側 — ライトプランのような「バックアップオプションを買う」行は無い

| 項目 | 置き方 | 月額 |
|---|---|---|
| microCMS | Team。有料プランの最安 | **4,900 円** |
| 配信 | Cloudflare Pages の無料枠 | **0 円** |
| ドメイン | `.com` の更新。年額 1,721 円（税込） | **143 円** |
| 保守 | PHP とプラグインの更新が無いので契約しない | **0 円** |
| 合計 | | **約 5,043 円** |

- 年額は **60,521 円** — Team 58,800 円 + ドメイン 1,721 円。Team は税抜、ドメインは税込
- Team に含まれる枠 — API **10** 個（追加は 2,000 円/個）、API キー **3** 個、メンバー **3** 人（追加は 1,200 円/人）、転送量 月 **200GB**（超過は 20 円/GB）
- キーが 3 個あるので、本番の GET と書き込みを分けられる — Hobby の 1 個ではこの分け方ができない
- 2要素認証の設定は全プランで可能 — 組織への必須化、権限管理、IP 制限は Team には無い。それらは前の記事の Business 以上
- この 5,043 円で揃う対策は、公開面から PHP と管理画面を外すこと、GET と WRITE のキーを分けること、アカウントの 2要素認証、描画する HTML を自分で扱うこと

> 参照: [microCMS 料金プラン](https://microcms.io/pricing) / [Cloudflare Pages](https://www.cloudflare.com/ja-jp/developer-platform/products/pages/) / [APIキー（APIの認証と権限管理）](https://document.microcms.io/content-api/x-microcms-api-key)

## 月額の差

| | WordPress | microCMS |
|---|---|---|
| ライセンス / CMS | 約 613 円（ACF PRO Personal） | 4,900 円（Team、税抜） |
| サーバー / 配信 | 330 円 | 0 円 |
| ドメイン | 143 円 | 143 円 |
| 保守 | 10,000 円 | 0 円 |
| 月額 | **約 11,086 円** | **約 5,043 円** |
| 年額 | **133,031 円** | **60,521 円** |

- 差は月 **約 6,043 円**、年 **72,510 円** — ドメインは両側で同じなので、差は保守と、Team と ACF・サーバーの差額
- サーバーを、自動バックアップ付きのハイスピード（月額 660 円）に上げても、WordPress は月 **約 11,416 円** — 差の説明は変わらない
- 保守を相場の上側、月額 30,000 円に置くと、WordPress は月 **約 31,086 円** — microCMS の 5,043 円との差は保守の置き方で開く
- 権限管理や IP 制限まで microCMS で揃えると Business の 75,000 円にドメイン 143 円が乗り、月 **約 75,143 円** — この表の大小は逆になる。その段差は前の記事

## この金額で守れる範囲

- WordPress の約 11,086 円で買うもの — WAF の付いた公開サーバー、ACF の更新、`.com` の更新、月ごとの本体とプラグインの更新、バックアップ、セキュリティ確認
- 公開オリジンに PHP と `/wp-admin/` は残る — 保守は、その面を放置しないための月額
- ライトは自動バックアップが標準に無い — 保守先が世代を残していない契約だと、330 円の行は「対策を揃えた」にならない。明細のバックアップを確認する
- microCMS の 5,043 円で買うもの — Team の入稿基盤、管理画面をベンダー側に置くこと、公開ファイルの無料枠、`.com` の更新、CMS の更新契約を持たないこと
- 5,043 円で買えないもの — 書く人と公開者の権限分離、管理画面の IP 制限、API 11 個目以降と 4 人目以降（追加料金）
- どちらも、リッチエディタの HTML をどう描画するかは月額の外 — 出力側の XSS はフロントの実装

## よくある間違い

### 1. サーバー月額だけを最安比較にする

- ライトの 330 円と Pages の 0 円の差は月 330 円 — ドメインは両側 143 円で差にならない。対策を揃えると比較の本体は、保守の 10,000 円と Team の 4,900 円
- ACF の年額 49 米ドルも、月割りすると保守の 1 割に満たない

### 2. エコノミーの 121 円を WordPress の行に置く

- エコノミーは WordPress の簡単インストールが無い — WordPress 対応の最安はライトの 330 円（36ヶ月）

### 3. Hobby の 0 円を、有料の最安として出す

- 有料の最安は Team の 4,900 円 — Hobby は転送 20GB で API が止まり、API キーも 1 個
- Team にも権限分離と IP 制限は無い — 承認フローの見積もりは、この記事の合計には入っていない

### 4. 保守 10,000 円に、障害復旧まで入っているとみなす

- この記事の 10,000 円は、更新、バックアップ、セキュリティ確認 — 改ざん除去や記事代行は別行の契約が多い
- 明細にバックアップが無い見積もりは、ライトの「自動バックアップなし」と重なる

## まとめ

- 対策を揃えた最安は、WordPress が月 **約 11,086 円**、microCMS が月 **約 5,043 円**
- ドメインは両側とも `.com` の更新 **年額 1,721 円**（月 143 円）— 差には入らない
- WordPress の残りは、ACF PRO Personal（この記事では月約 613 円）、ロリポップ ライト（36ヶ月で月 330 円）、保守（月 10,000 円）
- WordPress の合計の約 9 割は保守 — 本体とプラグインの更新、バックアップ、セキュリティ確認を、相場 1〜3 万円の下端で置いている
- サーバー最安のライトは WAF 付きで、自動バックアップは標準に無い — 切り戻しは保守の明細で確認する
- microCMS の残りは Team **4,900 円**（税抜）、Cloudflare Pages の無料枠 0 円、保守 0 円 — PHP とプラグインの更新契約が要らない
- Team には API キー 3 個と転送 月 200GB が付く — 権限分離と IP 制限は無く、その段は前の記事の Business
